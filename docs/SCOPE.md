# ATLAS Scope

## Purpose
Define what ATLAS assesses and the boundaries of each assessment.

## Authorisation
- Assess only assets for which explicit permission has been obtained.
- Record the asset owner, approved targets, permitted methods, and assessment window.
- Reject targets outside the approved scope.

## Intended scope
- Asset and host discovery within an approved scope.
- Port scanning and service enumeration within that scope.
- Technology and vulnerability intelligence correlation.
- Attack surface visualisation and risk prioritisation.

## Exclusions
Unauthorised scanning and any target not listed in the approved scope. Any intrusive testing requires separate explicit authorisation and an approved test plan.
